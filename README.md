# Fashion Mart Fresh Build
Responsive Bengali fashion storefront. Static files: index.html, style.css, shop.js, checkout.html, admin.html, track.html.

IMPORTANT: front-end prototype only. Products and cart use browser localStorage; admin has no secure authentication, and checkout does not submit orders to a server or Telegram. Connect a secure PHP/API backend and database before accepting real customer orders. Keep bot tokens server-side.
